Before you install

Setup and compatibility

Finish or cancel all Canon jobs before changing drivers. You can install over an existing project driver. Queues, printer options and the default printer are preserved.

When exactly one LBP2900 is connected and the queue name is free, installation creates the correct printer connection and starts its status service. Existing queues are preserved; ambiguous devices require manual setup.

After installation

Open System Settings → Printers & Scanners → Canon LBP2900 → Options & Supplies → Utility. Native Canon dialogs remain in English. Experimental: tested on LBP2900 / Apple Silicon / macOS 27.2; LBP2900B, Intel and reboot recovery need further testing. The package is ad-hoc signed, without Developer ID Installer/notarization.
