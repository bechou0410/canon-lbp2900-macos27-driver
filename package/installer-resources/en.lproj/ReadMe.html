Installation notes

Install or update

Install over an intact project driver. Printer queues, settings and the default printer are preserved.

USB setup

Connect one supported printer by USB for automatic setup when the queue name is available. Existing queues or multiple printers may need manual setup.

Compatibility

Tested: LBP2900 · Apple silicon · macOS 27.2. LBP2900B, Intel and restart recovery need further testing.
